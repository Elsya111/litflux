五种读法

同一份项目脉络、同一组交互（分解、判断、阅读、源码），五种完全不同的界面主张。全部为可点击的静态设计稿，使用虚构的 Lumen 演示项目，不改动生产查看器。

基准 1440 × 900演示数据 3 入口 · 15 节点技术 原生 HTML / CSS / JS状态 设计稿，未验收
01

纸本

Paper / Minimal

以图为先：侧栏与节点说明默认收起，正交连线、统一箭头，按窗口自适应铺满；纸色界面可切换黑夜。需要解释时再展开侧栏或底部说明，不打断图面。

图优先面板默认收起正交连线按屏适配黑夜模式 打开纸本 OPEN → 02

蓝图

Blueprint

工程制图的隐喻：深蓝图纸、坐标网格、图号与标题栏。每一次选择都变成一次标注，右侧注释与图中的编号引线一一对应。

等宽字体标题栏编号引线坐标读数 打开蓝图 OPEN → 03

篇章

Editorial

把一次业务流程读成一篇文章。左侧图版固定，右侧正文滚动；章节、摘要、编号段落与图注，让“解释”成为第一等公民。

杂志跨页图版 + 正文章节编号滚动阅读 打开篇章 OPEN → 04

终端

Terminal

给愿意用键盘的人：三窗格、等宽字、状态行与命令行。↑↓ 选节点，r 阅读，n 下一步，/ 直接输入命令切换入口。

键盘优先三窗格命令行ASCII 树 打开终端 OPEN → 05

柔和

Soft / Organic

面向非工程读者：圆角卡片、柔和色块与浮动阅读岛。业务脉络变成可分层的胶囊，点开节点从右侧滑出说明，源码从底部展开。
